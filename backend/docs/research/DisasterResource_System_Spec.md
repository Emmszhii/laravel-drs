# DisasterResource+ — System Specification

Superseded by [`backend/docs/system-spec.md`](../system-spec.md), the spec the system is built to.

This file was the first draft from the Capstone paper (Chapters I–III). It had Logistics running the solver and endorsing each recommendation to the Head of Office. That flow was dropped on 2026-09-29: the Head of Office (Admin) enters the budget, runs the solver and approves; Logistics only encodes; and the Admin has every other role's capabilities. The draft is in git history (commit `9becdc0`).
